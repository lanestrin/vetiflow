## Goal

The patient record stops scrolling inside its own box on desktop, so there is one scrollbar, and its header takes the designer's compact layout: name, acuity, More actions and a close ✕ on one row, then the meta line, Stage and Location, and the allergy line. Staff see more of the record at once and can close it to return to the board where they left it.

## In scope

- **One scrolling surface.** At 1051 px and wider the panel is no longer sticky, has no `max-height` or own scrollbar, and its header (`.fixedTop`) is no longer pinned. The page is the only scrolling surface. Below 1051 px nothing changes (the panel sits under the board until 2.27).
- **Top row.** Patient name (the existing `h3`, still the focus target after load), then the acuity control, then More actions and the close ✕ on the right. It wraps on narrow widths without horizontal scroll.
- **"Patient record" heading.** The `h2` stays in the DOM as the panel's accessible name (`aside` labelled by it) and the existing focus fallback. While a patient is shown it is visually hidden; with no patient, loading, not found or failed, it shows as today.
- **Acuity control.**
  - Not discharged: a button containing the existing `AcuityBadge` and a ⌄. Accessible name "Change acuity, currently <badge text>" (for example "Change acuity, currently Critical · provisional"). Pressing it opens the same triage dialog that More actions' Complete triage / Re-triage opens, with the same `editingCase` and focus return to the acuity button.
  - Discharged: the plain badge, no button, as stage and location are read-only there.
  - It adds no new permission and no new path: acuity changes only through the existing triage endpoint and `EmergencyCase.RecordTriage`.
- **Close ✕.**
  - A button with accessible name and `title` "Back to patient board".
  - It asks the panel's owner to clear the selection. On the ER board that goes through the same unsaved-draft guard as choosing another patient (`drafts.requestLeave`).
  - After closing, the panel shows its empty state. The board's filter, search, sort, page and scroll position are unchanged.
  - Focus moves to the closed patient's name button on the board without scrolling (`preventScroll`), or to the board's heading if that patient is no longer listed.
- **Meta line.** "Dog · German Shepherd · 8y · 36.2 kg", then the case reference inline and muted: "Case ER-2401 · Checked in 1:25 AM". The separate case line under the old title goes.
- **Stage and Location.** Each button shows its small label and value on one line with a ⌄ on the right, keeping today's accessible names ("Change care stage, currently In treatment"). Discharged: plain text without ⌄.
- **Compact spacing** from the prototype for the header, allergy line, tabs and the Clinical tab (values in the inventory).
- **Target sizes.** At 1050 px and below, every header control (acuity, More actions, ✕, Stage, Location, allergy line, tabs) is at least 44 px tall. Desktop may use the prototype's smaller sizes, none under 30 px.
