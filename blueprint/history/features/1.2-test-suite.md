## Goal

Give both halves of VetiFlow a real test suite and run it on every PR, so
later features can be verified instead of assumed.

## In scope

- **Server:** `vetiflow.Server.Tests`, xUnit v3 on Microsoft.Testing.Platform.
  - Unit tests for `EmergencyCase.RecordTriage` and `EnumColumnMigration`.
  - API tests through `WebApplicationFactory`: case list contract and order,
    stage updates (204, 404, 400), SignalR `caseUpdated` broadcast, health check.
  - Database tests against real Postgres: active-case unique indexes,
    restrict-delete foreign keys, enums stored by name.
  - Migration tests: model matches snapshot, up/down/up round trip,
    `DataModelIntegrity` converts integer enums by name.
  - Seeder idempotency.
  - Postgres from Testcontainers, or an existing server through
    `VETIFLOW_TEST_POSTGRES`; each run uses throwaway databases.
- **Client:** Vitest, React Testing Library and MSW. Tests for every component,
  both services, the ER board page and routing. Unhandled requests fail tests.
  ESLint rules for Vitest and Testing Library. Coverage via `@vitest/coverage-v8`.
- **CI:** `.github/workflows/ci.yml` runs server tests, client lint, build and
  tests on pushes to `main` and on PRs.
- **Cleanup:** EF Core Relational pinned to 10.0.11; `npm audit fix` (vite 8.3.5
  and transitive patches); workflow lanes labelled by their heading.
