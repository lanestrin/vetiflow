## Goal

A veterinarian or technician can set My status (Busy, Available, At limit,
Unavailable) from any staff page, and a toast confirms it ("Availability set
to Busy"). The status feeds the clinicians on floor count (2.21a).

## Design reference

`blueprint/reference/vetiflow-er-dashboard.html`, `.availability` in the My
patients header (`#availabilityStatus`):
`<div class="availability"><span>My status</span><select aria-label="Set availability">`
with the options Busy, Available, At limit and Unavailable, in that order.
On change it toasts "Availability set to <option>".

- **`.availability`:** flex, gap 9px, white, `--line` border, radius 10px,
  padding 8px 10px, 11px muted label.
- **The select:** no border, transparent, teal 700 11px.

**Placement (decided 2026-10-29):** My patients (2.22b) is not built yet, so
the control goes in the top bar's profile menu, between the name and **Sign
out**, on every staff page. 2.22b adds the same control to its header.

## In scope

- **`MyStatusControl`:** the prototype's control, with a visible
  `:focus-visible` outline in place of the prototype's `outline: 0`. The
  select's accessible name is "My status", from its visible label.
- **Loading:** each time the profile menu opens, it reads
  `GET /api/staff/me/status`. The control shows once the status has loaded.
- **Who sees it:** only clinicians. A `403` (a receptionist, assistant or
  manager) shows no control and no error. The server decides, so the client
  holds no role list.
- **Saving:** choosing an option sends `PUT /api/staff/me/status` and shows
  the chosen value straight away.
  - On success, it toasts "Availability set to Busy", using the option's label.
  - On failure, the select goes back to the saved value and it toasts
    "Couldn't save your status. Try again."
  - While a save is in flight, the select is disabled.
- **Errors:**
  - A load that fails for any other reason shows "Status unavailable" in muted
    text, with no select.
  - A `401` on load or save clears the token and goes to sign-in with
    `sessionEnded`, as the board does.
- **Labels** live in the client: Available, Busy, At limit, Unavailable.

## Out of scope

- The My patients workspace and its header control (2.22b). The shift chip's
  count (2.15b).
- Live updates of other people's status (no hub message yet, 2.21a).
- Any server change.
