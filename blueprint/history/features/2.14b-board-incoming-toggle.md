## Goal

The board's header gets the prototype's **Incoming** toggle with its count, so
staff can switch the triage queue on and off from the board itself. It is the
same filter as the Awaiting triage stat card (2.12b): either one presses both.

## Design reference

`blueprint/reference/vetiflow-er-dashboard.html`:

- **Markup:** `.boardtop` and `.boardtools`, with
  `<button class="toolbtn" id="triageToggle" aria-pressed="false">⇣ <span>Incoming</span> <b>3</b></button>`.
- **Layout:** `.boardtop` is a flex row: the title and "Updated…" on the left,
  the tools on the right (gap 7px).
- **`.toolbtn`:** border `--line`, white, radius 8px, padding 7px 9px,
  `#64767c` 11px/600. When pressed (`.active`), it turns navy with white text.
- **Phone width (650px):** the label span is hidden, leaving "⇣ 3".
- **Behaviour (`toggleTriageFilter`):** when the triage filter is on, the
  toggle shows all patients again. Otherwise it turns on the Awaiting triage
  filter, the same as the card: the card and toggle are pressed together, and
  an empty queue toasts "No patients awaiting triage".

## In scope

- **The toggle:** `PatientFlowBoard`'s header gets a `.tools` group with the
  Incoming toggle. It is a button with `aria-pressed` (true while the filter
  is `awaitingTriage`) and the accessible name "Incoming, N awaiting triage".
- **The count:** the number of loaded cases in stage Incoming. That is exactly
  what the toggle shows, and it updates with every board reload.
- **Pressing it:** `PatientFlowBoard` takes an `onFilter` callback. The toggle
  asks for `"all"` when the filter is `awaitingTriage`, and for
  `"awaitingTriage"` otherwise. `ErBoardPage` passes its existing
  `chooseFilter`, so the empty-queue toast and the stat card's pressed state
  come with it.
- **Styles:** `.toolbtn` from the prototype, using the existing tokens
  (`--color-shell-line`, `--color-shell-navy`). At 650px the label is hidden
  visually but stays in the accessible name.

## Out of scope

- **Filter** (2.14c) and **Priority** (2.14d). The `.tools` group is where
  they go later, but they aren't added now.
- Any change to the stat cards or to what the Awaiting triage filter shows
  (2.12b).
