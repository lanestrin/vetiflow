## Goal

The board's Filter menu can narrow the board by acuity and by staff assignment, including patients still missing a technician or a veterinarian, so staff find "Jordan's patients who still need a technician" in two choices.

## Design reference

- `blueprint/reference/er-board-poc/VetiFlow-ER-Prototype.html`: `#filters` (`Acuity` with All acuities / Critical / Urgent / Stable; `Staff assignment` with All teams / Unassigned / staff names; `Clear`). The app keeps 2.14c's menu look (`board-toolbar.png` shows the Filter button).
- Decision (2026-11-02, by the person): **Staff** replaces 2.14c's **Clinician** filter.
- **Element inventory:**

  | Prototype element | This item |
  | --- | --- |
  | Acuity select: All acuities, Critical, Urgent, Stable | Built as "Acuity": Any acuity, Critical, Urgent, Stable |
  | Staff assignment select: All teams, Unassigned, names | Built as "Staff": Any staff, No technician assigned, No veterinarian assigned, then named staff. "Unassigned" is the toolbar's toggle (2.26b), not an option here |
  | (current app) Clinician select with Unassigned | Removed by decision |
  | (current app) Species and Case status selects | Unchanged |
  | Clear | 2.14c's "Clear filters", unchanged |

## In scope

- **Menu order:** Acuity, Staff, Species, Case status, then Clear filters when any filter is in use.
- **Acuity:** "Any acuity", "Critical", "Urgent", "Stable". A choice shows only cases with that acuity.
- **Staff:**
  - "Any staff", "No technician assigned", "No veterinarian assigned", then every person assigned on the board as primary technician or attending veterinarian, once each, by name, sorted.
  - A name shows the cases where that person is the assigned technician or the attending veterinarian.
  - "No technician assigned" shows cases with no primary technician; "No veterinarian assigned" shows cases with no attending veterinarian.
  - A chosen person stays in the list after a reload even when no case has them any more (2.14c's rule), so the selection never jumps.
- **Clinician removed:** the select, its "Unassigned" option and the `clinician`-based matching go. The list item's `clinician` field stays for its other uses.
- **Combining:** every filter in use must match (AND): the stat card, the Filter menu's four selects, the Unassigned toggle and search. For example, Unassigned with Staff "Jordan Lee" shows Jordan's patients who still need a technician.
- **Filter count:** the button's "Filter, N in use" counts Acuity and Staff too.

## Out of scope

- Species, Case status, the stat cards, the Unassigned toggle, search and the sort: unchanged.
- My patients (2.28).
