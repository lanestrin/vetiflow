# Fixes

`/complete` archives each finished `/fix` here as `YYYY-MM-DD-<short-name>.md`.
Fixes are bugs and small changes that were not build-plan items. Together with
`history/features/`, they are the full build history.

Same rule as features: a file is final once its PR merges. Review changes before
the merge update its `## Result`; after the merge, never edit it.
