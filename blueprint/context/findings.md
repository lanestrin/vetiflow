# Findings

> **Generated file.** Problems `/audit` found in the current work, each with an
> ID, a severity and a status. `/implement` marks a repaired finding `fixed`, a
> later `/audit` moves it to `closed`. `/complete` refuses to finish while any
> P0 or P1 finding is `open` or `fixed`, then archives the findings with the
> spec and resets this file.
>
> Severity: **P0** data loss, security break, cannot ship. **P1** likely bug,
> broken contract, missing guard. **P2** maintainability issue worth fixing
> before the item closes. **P3** small cleanup or follow-up idea.
>
> Status: **open** found, not repaired. **fixed** repaired, waiting for a
> re-audit. **closed** re-audit confirmed. **accepted** you decided to live
> with it (only you can accept a finding, and only P2 or P3).
